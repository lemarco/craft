# Release 0.7.0 (unreleased)

Pre-1.0 API polish — capabilities-first facade and gateway naming.

## Facade

- **`TrembitaAppBuilder::from_env` / `from_config`:** when `TREMBITA_LISTEN` is set, mount ops + registration-driven product HTTP by default; `/actors/*` remains opt-in ([`without_actors_api`](../../crates/trembita/src/app/builder.rs), [`WorkerOpts::http_cast`](../../crates/trembita/src/worker_opts.rs)).
- Builder sugar: [`without_ops`](../../crates/trembita/src/app/builder.rs), [`without_jobs_api`](../../crates/trembita/src/app/builder.rs), …, [`with_actors_api`](../../crates/trembita/src/app/builder.rs).
- **`prelude`:** drops legacy worker/session error re-exports; use crate root for [`WorkerOpts`](../../crates/trembita/src/worker_opts.rs), [`OpenWorkerSessionError`](../../crates/trembita/src/gateway/session.rs).

## Breaking (deprecated one release)

Gateway sticky session helpers renamed ([ADR](../decisions/gateway-session-naming.md)):

| Deprecated | Replacement |
|------------|-------------|
| `OpenActorSessionError` | `OpenWorkerSessionError` |
| `open_actor_session*` | `open_worker_session*` |
