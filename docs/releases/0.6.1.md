# 0.6.1

Patch release: **`trembita-capstore`** crate on crates.io, optional Postgres cap store, Redis adapter maintenance.

## Cap store crate rename

| Before | After |
|--------|--------|
| `trembita-actor-store` (implementation) | **`trembita-capstore`** |
| `ActorStateStore` | **`CapStateStore`** (deprecated alias kept) |
| `RedbActorStateStore` | **`RedbCapStateStore`** (deprecated alias kept) |

`dependency` line:

```toml
trembita-capstore = "0.6.1"
```

**`trembita-actor-store` 0.6.1** remains on crates.io as a **deprecated re-export** of `trembita-capstore` for one transition cycle.

Product surface unchanged: [`trembita::capstore`](../../crates/trembita/src/capstore.rs). Facade adds deprecated `trembita::actor_store` module alias.

## Optional integrations (O-01 / O-02)

- **`trembita-store-redis`** — depends on `trembita-capstore`; docs/examples use `CapStateStore`.
- **`trembita-capstore-postgres`** — new optional Postgres `CapStateStore`; facade feature **`capstore-postgres`**.

## Upgrade

```bash
cargo update -p trembita -p trembita-capstore
cargo check
```

Replace direct `trembita-actor-store` deps with `trembita-capstore` when convenient; aliases work through 0.6.x.
