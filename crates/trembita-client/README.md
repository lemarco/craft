# trembita-client

Client API for [trembita](https://crates.io/crates/trembita): typed propose/query helpers,
in-process routing, and remote HTTP/3 clients with leader forwarding and retries.

Use this crate when building application clients that talk to a live cluster.
Most server-side embedders depend on the [`trembita`](https://crates.io/crates/trembita)
facade instead.
